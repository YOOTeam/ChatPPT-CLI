# ChatPPT-CLI 安装与使用指南：给 AI Agent 装上专业 PPT 制作“双手”



## 一、ChatGPT-CLI 是什么？

**ChatPPT-CLI** 是 ChatPPT 官方开源的命令行工具（GitHub 仓库：[https://github.com/YOOTeam/ChatPPT-CLI](https://github.com/YOOTeam/ChatPPT-CLI)），旨在为 AI Agent 提供标准化、可编程的 PPT 生成、编辑与导出全流程能力。

大模型虽然能生成文字、理解需求，但要真正交付一份排版精美的演示文稿，仅靠文字远不够。ChatPPT-CLI 让 AI Agent 不再只输出“建议的大纲”，而是**调用封装好的核心能力，直接对 PPT 文档进行操作——从创建、编辑、美化到导出，一条龙完成**。

ChatPPT-CLI 的核心定位是为 **AI Agent 使用方式专门设计**，并非简单包装现有 API。它针对 token 消耗、状态追踪和错误自愈等 AI 对话场景进行了深度优化，使 AI 能更高效、更可靠地完成 PPT 任务。

> \*\*一句话总结：\*\* 你只需用自然语言描述 PPT 需求，AI 负责调用 ChatPPT-CLI 就像操作自己的双手，你负责下载使用。

ChatPPT-CLI 是 YOOTeam 在 PPT 生成领域的开源力作，与 [OpenPPT](https://github.com/YOOTeam/OpenPPT)（AIPPT 在线编辑器，1.1k+ Stars）共同构成了 ChatPPT 生态的核心工具链。当前已覆盖以下能力域：导入能力、查询能力、文档生成、文档编辑、其他创作、结果导出、商业化功能。



## 二、ChatPPT-CLI 快速安装与认证

### 从 GitHub 获取

ChatPPT-CLI 源码开放在 [YOOTeam/ChatPPT-CLI](https://github.com/YOOTeam/ChatPPT-CLI)，采用 GNU General Public License v3.0 协议。你可以直接克隆仓库或下载预编译版本。

```bash
# 克隆仓库
git clone https://github.com/YOOTeam/ChatPPT-CLI.git
cd ChatPPT-CLI

# Go 开发构建
go build -o chatppt .

# Go 生产构建 (优化)
go build -ldflags "-s -w" -o chatppt .
```

更多安装方式（包括交叉编译 Linux/Windows 版本）和详细使用说明，请参阅仓库 README 和文档目录。

配置完成后，重启你的 AI Agent 工具即可通过标准 CLI 协议调用 ChatPPT 能力。

### 完成用户认证

ChatPPT-CLI 通过安全的设备码流程完成用户授权，凭证自动保存在系统密钥链中：

```bash
# 自动打开浏览器完成授权
chatppt auth login

# 不自动打开浏览器，手动输入验证码
chatppt auth login --open=false
```

> 📌 认证后，AI 才能以你的身份生成、编辑和管理 PPT，并正常调用远程服务。你可使用 `chatppt auth status` 随时查看登录状态，也可通过 `chatppt auth logout` 退出。



## 三、ChatPPT-CLI 核心能力详解

ChatPPT-CLI 将复杂的 PPT 制作流程封装为分类清晰的命令集，让 AI 可以直接操作。以下是全量能力一览：

### 导入能力

|功能接口|说明|AI 能为你做什么|
|-|-|-|
|**本地模板导入**|上传本地 PPT 模板到 ChatPPT 服务端模板库|你提供喜欢的模板文件，Agent 将其导入到账户中，供后续一键应用|
|**本地 PPT 导入**|上传本地 PPT 文件并转成在线文档|你想继续编辑一份已有的 pptx，Agent 帮你转为在线版，并返回在线编辑器 URL|
|**本地文件转 PPT**|上传图片、PDF 等文件，自动转换为 PPT 文档 JSON|你有一份 PDF 或图片素材，Agent 直接将其变成可编辑的 PPT 文档|
|**文档整合**|将 pptx、png、pdf 等文件插入到指定 PPT 文档的指定位置（某页之前/之后）|你需要在现有 PPT 中补充内容，Agent 按你说的页数精确插入，生成合并后的文档|
|**截图获取**|对文档某一页进行截图，生成图片用于绘图编辑等用途|需要引用某一页的画面？Agent 帮你截取并生成图片文件|

### 查询能力

|功能接口|说明|AI 能为你做什么|
|-|-|-|
|**关键字查询**|用关键词搜索文档库/文件库中的文件|“帮我找我上周做的年终总结” — Agent 用关键词瞬间定位文档|
|**文件列表读取**|读取所有上传的文件列表，返回名称、ID、类型等|记不清有什么素材？Agent 拉出完整文件清单给你|
|**文档列表读取**|读取所有已创建的 PPT 文档列表，返回名称、ID、格式等|项目太多，Agent 帮你列出所有在线 PPT 文档，一目了然|

### 文档生成

|功能接口|说明|AI 能为你做什么|
|-|-|-|
|**经典模式生成**|根据主题描述，按经典生成路径直接输出 PPT 文件|“生成一份关于新能源汽车趋势的 PPT” — Agent 负责从文字到排版，交付成品|
|**绘图文档生成（Banana）**|通过 Banana 绘图模型生成更精美的 PPT，可选择风格、文档类型等|需要视觉冲击力的发布会 PPT，Agent 调用 Banana 引擎，提供多种创意风格|

### 文档编辑

ChatPPT-CLI 提供了丰富的编辑能力，划分为“绘图文档编辑”“在线文档编辑”“通用文档编辑”三类，覆盖从美化到动效的所有高频需求。

**绘图文档编辑（Banana 风格文档）**

* **全文美化**：Agent 会主动向你询问创作风格偏好，根据选择对整份文档进行美化，生成新版本。
* **单页美化**：只想美化某一页？Agent 精准优化指定页面，其他不动。
* **新增绘图页面**：根据指令或上传的文档，绘制新页面并插入到指定位置（默认最后一页），与原文档无缝合并。

**在线文档编辑（经典模式文档）**

* **全文美化**：基于预置模板库，一键替换全文模板，即刻提升文档设计感。
* **单页美化**：同样支持单页模板替换，局部微调随心所欲。
* **新增页面**：按经典 PPT 方式生成新页，并合并入原文档，位置可指定。
* **换字体**：全文一键替换为你指定的字体，支持所有可用字体。
* **换主题色**：一键切换全文主题色，适配不同演示场景。

**通用文档编辑**

* **删除单页**：删除指定单页或连续多页，文档自动重新组织。
* **动画渲染**：为全文添加流畅的动画效果，让演示更生动。

### 其他创作

|功能接口|说明|AI 能为你做什么|
|-|-|-|
|**演讲稿生成**|为文档自动生成分页演讲稿，写入备注并单独导出 txt 文件|“帮我写好讲稿，我要准备演讲了” — Agent 给你一份完整的演讲词和备注版 PPT|
|**AI 路演创建**|为文档生成 AI 路演链接，支持选择 AI 声音并包含图片文本识别|想生成可分享的自动播报路演？Agent 帮你创建链接，还让你挑喜欢的音色|
|**音色读取**|列出可用 AI 音色选项及参数|不确定有哪些音色？Agent 拉出清单供你挑选|

### 结果导出

|功能接口|说明|AI 能为你做什么|
|-|-|-|
|**在线编辑器获取**|获取任一文档的在线编辑链接|想手动微调？Agent 直接给你网页版编辑入口|
|**文件获取/下载**|下载文档的 pptx、png 或 pdf 文件，默认 pptx|“给我下载成 PDF” — Agent 立刻准备好下载链接|
|**导出演讲稿**|单独导出已生成演讲稿的完整文稿（txt）|只要文字稿？一句话导出|
|**导出内容文件**|单独导出文档的文字内容稿|想用文本再加工，Agent 导给你|

### 商业化功能

|功能接口|说明|作用|
|-|-|-|
|**用户鉴权**|首次使用前通过账户密码登录，通信加密|安全保障，Agent 会提醒你密码仅自己保管|
|**身份校验**|校验用户会员身份（如 SVIP）|某些高级功能需要特定身份，Agent 自动检测并告知|
|**消耗记录**|查询功能点数消耗情况|每次执行操作，Agent 可返回本次消耗点数，消费透明|
|**权益校验**|请求前判断用户是否有权限执行该功能|避免无权限操作失败，Agent 提前告知是否可用|



## 四、ChatPPT-CLI 典型使用场景

> 温馨提示：以下命令示例仅供了解 CLI 能力。当你使用 AI Agent 时，只需用自然语言说出你的需求，AI 便会自动调用相应命令。

### 场景 1：将现有文档转成精美 PPT

你有一份项目汇报的 Word 文档，想让 AI 帮你做成 PPT，并想用 Banana 风格让它更专业。

1. Agent 使用“本地文件转 PPT”导入 Word 文档，拿到在线文档 ID 和编辑器链接。
2. 再用“绘图全文美化”或“经典全文美化”，根据你选定的风格一键套用模板。
3. 最后通过“文件获取/下载”下载为 pptx。

你全程只需说：“把这份项目报告做成一个高级商务风 PPT，字体用思源黑体，主题色蓝色，然后给我下载 pptx。”

### 场景 2：对着已有 PPT 进行精细化编辑

已有一份在线 PPT，你需要新增一页“竞品分析”，并删除第 3 页旧数据，再为全文添加动画。

Agent 依次执行：

* “新增页面（绘图或经典）” — 生成竞品分析单页并插入指定位置。
* “删除单页” — 删除第 3 页。
* “动画渲染” — 为全文添加动效。
* 结束后返回新版本文档的在线编辑链接。

### 场景 3：演讲准备一站式搞定

明天就要上台，你有一份 PPT，但还没写讲稿，也想要一个 AI 自动播报的路演链接。

Agent 组合调用：

* “演讲稿生成” — 自动生成备注和独立 txt 文稿。
* “音色读取” + “AI 路演创建” — 让你选一个喜欢的 AI 音色，生成路演链接。
* “导出演讲稿” — 导出一份纯文本书，方便你彩排。

### 场景 4：资源管理——查找与整合

你积累了很多模板和文档，想让 AI 找出上季度销售模板，并把最新销售数据 PDF 插入其中。

Agent 使用：

* “关键字查询” — 快速定位“销售模板”文档 ID。
* “文档整合” — 将 PDF 数据插入该文档第 4 页之后。
* 最后返回更新后的编辑器链接。



## 五、为什么选择 ChatPPT-CLI

### 你的 AI 需要一双手，一双专业的 PPT 制作手

AI 能生成文字，但不能直接产出排版精美、结构严谨的 PPT。ChatPPT-CLI 就是那双“专业的手”。

### 开源透明，社区共建

ChatPPT-CLI 在 GitHub 完全开源（[YOOTeam/ChatPPT-CLI](https://github.com/YOOTeam/ChatPPT-CLI)），采用 GNU GPL v3.0 协议。开发者可自由审计代码、提交 PR、提出 Issue，与 YOOTeam 的 [OpenPPT](https://github.com/YOOTeam/OpenPPT)（1.1k+ Stars, 88+ Forks）等开源项目共同构成完整的 PPT 生成工具生态。

### 为 AI Agent 量身定制，非简单 API 包装

* **SSOT 输出设计**：所有命令默认返回 JSON 格式，AI 解析简便，降低 Token 消耗，提升成功率。
* **智能状态追踪**：内置 `--poll` 轮询机制，AI 可配置间隔自动跟踪生成进度，无需反复追问。
* **容错引导**：认证失效、文件格式不支持、API 超时等场景，CLI 输出明确修复指引，AI 可据此自愈或反馈用户。

### 全流程能力覆盖，一站完成 PPT 生命管理

从导入、生成、编辑、美化，到导出、路演、演讲稿生成，ChatPPT-CLI 覆盖了 PPT 制作与分发的每一个环节，完全由 AI 驱动。

### 简单集成，零学习成本

安装后立刻可用，天然适配 AI 工具链。你的自然语言指令就是最高效的调用方式。



## 六、常见问题解答 FAQs

### 如何让 AI 按我的自然语言操作 PPT？

AI 会自动将你的描述转换为相应的 CLI 命令。你只需说明“想做什么”，AI 会选择合适的导入、生成、编辑或导出命令组合完成。

### 首次使用需要做什么？

安装 CLI 后，执行 `chatppt auth login` 按照提示在浏览器授权即可。AI 会在需要时自动提示你完成认证。

### 文件上传失败或导入失败怎么办？

请检查：

1. BCE/存储配置是否正确（AK/SK、Endpoint、Bucket）；
2. 网络能否访问存储服务；
3. 文件格式是否支持（pptx, docx, pdf, png, txt, md 等），大小是否在限制内（最大 100MB）；
4. 用 `--debug` 模式查看更多错误详情。

### 如何查看我的消耗情况？

AI 在执行功能后会根据返回参数告知本次消耗。你也可以让 Agent 使用消耗记录查询接口，列出历史消耗明细。

### 支持哪些导出格式？

目前支持 pptx、png、pdf。默认导出 pptx。Agent 会根据你的要求调用相应导出命令。

### 源代码在哪里？

ChatPPT-CLI 完全开源，GitHub 仓库地址：[https://github.com/YOOTeam/ChatPPT-CLI](https://github.com/YOOTeam/ChatPPT-CLI)。欢迎 Star、提 Issue 或贡献 PR。

### 如何查看所有可用命令？

```bash
chatppt --help
chatppt ppt --help
# 以及各个子命令的帮助，如：
chatppt ppt generate --help
```

### 我已有在线 PPT，如何获取在线编辑链接？

让 Agent 使用“在线编辑器获取”功能即可，它会基于文档 ID 返回可直接在浏览器编辑的链接。
